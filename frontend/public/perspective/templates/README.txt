HOW TO ADD YOUR REAL IMAGES
=====================================================
This folder contains the template image placeholders for the 8 Spatial Perspective Taking scenarios.

For each scenario (scenario_1 to scenario_8), you have 6 views:
1. main_view_1.svg  -> Main View 1
2. main_view_2.svg  -> Main View 2
3. perspective_a.svg -> A's Perspective
4. perspective_b.svg -> B's Perspective
5. perspective_c.svg -> C's Perspective
6. perspective_d.svg -> D's Perspective

You can overwrite these SVG files directly with your SVG, PNG, or JPG files (keeping the same filenames, or updating the extension in frontend/src/tasks/perspective/perspectiveData.ts).
